<details open>
<summary><b>🎬 YouTube Trending Data Pipeline</b> &nbsp;|&nbsp; <code>AWS Step Functions · Lambda · Glue PySpark · Athena</code></summary>

<br/>

> **Cloud-native multi-region ETL pipeline** that ingests YouTube trending data across **10 countries**, enforces data quality gates, and produces analytics-ready Gold tables — fully orchestrated and scheduled.

| Layer | Service | Key Action |
|---|---|---|
| 🥉 **Bronze** | Lambda + S3 | Raw JSON from YouTube Data API v3 & Kaggle CSVs |
| 🥈 **Silver** | Glue PySpark | Schema enforcement, null handling, dedup, `like_ratio` / `engagement_rate` |
| ✅ **DQ Gate** | Lambda | Row count ≥10, null % ≤5%, schema check, freshness <48h |
| 🥇 **Gold** | Glue PySpark | `trending_analytics`, `channel_analytics`, `category_analytics` |

**📐 Architecture highlights:**
- ♻️ Step Functions orchestration with **retry logic + parallel Silver transforms**
- ⏰ EventBridge schedule: **every 6 hours**, fully automated
- 🔔 SNS failure alerts — pipeline never silently fails
- 🌍 Regions: US · GB · CA · DE · FR · **IN** · JP · KR · MX · RU
- 📊 Query-ready in **Athena** + exportable to QuickSight dashboards

<summary><b>📺 StreamVibe Analytics Platform</b> &nbsp;|&nbsp; <code>AWS Glue Visual ETL · S3 · Athena · Redshift · PySpark</code></summary>

<br/>

> **End-to-end Medallion Data Lake** for an Indian OTT platform scaling from **500K → 5M users**. Processes **14,000+ streaming records**, answers 6 critical business questions via Athena in under 10 seconds.

| Business Stakeholder | Question Answered | Gold Table |
|---|---|---|
| 📺 Content Team | Which titles drive the most watch time? | `content_performance` |
| 📈 Content Team | Which genres are gaining/losing momentum? | `genre_trends` |
| 👥 Product Team | Power users vs casual vs churned? | `user_segments` |

| 📱 Device Team | Which devices do Premium users prefer? | `user_segments` |

**📐 Architecture highlights:**
- 🏗️ Built with **AWS Glue Visual ETL** (zero raw PySpark required)
- 🧹 DQ pipeline: Filter → Change Schema → Evaluate DQ (DQDL) → Drop Duplicates
- 💾 **Parquet output with intelligent partitioning** — reduced Athena scan costs
- 🔎 Athena SQL validation queries prove all 6 KPIs return correct results
- 🗄️ Analytics layer in **Amazon Redshift** + Athena
